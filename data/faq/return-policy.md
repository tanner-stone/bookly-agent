# Returns and refunds

Refunds cover the whole order.

If we delivered the order in the last 30 days and the total was $50 or less, we can refund it.

If you have never had a refund with us, we can make a one-time exception for an order up to $150 that was delivered in the last 45 days.

An order that is still on the way is too early to refund.

A cancelled order is already closed. We do not start another refund for it.

An order that was already refunded cannot be refunded again.

Anything else is reviewed by a person. Email support@bookly.example or call 1-800-555-0148.
